單元核心觀念心智圖 (Concept Map)

快速掌握絕對值與數線三大核心觀念

Branch 01

距離與分點公式

  • • 幾何距離：$d(A, B) = |a - b|$。
  • • 內分點公式：$P(x) = \frac{na + mb}{m + n}$（交叉相乘）。
  • • 外分點公式：$x = \frac{-na + mb}{m - n}$。
Branch 02

絕對值方程式與不等式

  • • 小於包中間：$|x-a| \le k \iff a-k \le x \le a+k$。
  • • 大於分兩邊：$|x-a| \ge k \iff x \ge a+k \text{ 或 } x \le a-k$。
  • • 參數反求：中心點 $a = \frac{c+d}{2}$，半距離 $b = \frac{d-c}{2}$。
Branch 03

三角不等式與極值

  • • 基本定理：$||a| - |b|| \le |a \pm b| \le |a| + |b|$。
  • • 加號等號：$|a + b| = |a| + |b| \iff ab \ge 0$。
  • • 減號等號：$|a - b| = |a| + |b| \iff ab \le 0$。

段考常踩四大盲點陷阱

考前自我檢查警示卡

陷阱 1：絕對值小於負數時盲目套公式

❌ 錯例：若題目為 $|x - 3| \le -2$，誤套用 $-2 \le x - 3 \le 2$。
✅ 正解：絕對值結果必 $\ge 0$，不可能小於等於負數，故直接判斷為「無解」！

陷阱 2：分區討論後漏掉檢查「假設條件」

❌ 錯例：在假設 $x \ge 3$ 的區域算出來 $x = 1$，直接寫入答案中。
✅ 正解：$x = 1$ 不符合 $x \ge 3$ 的前提，屬於增根（無效解），必須嚴格捨去！

陷阱 3：參數反求時忘記調整「對齊係數」

❌ 錯例：解出的中心半距離為 $|x - 3| \le 5$，面對題目 $|ax + 3| \le b$ 時直接對照 $a = 1$。
✅ 正解：注意常數項為 $+3$，兩邊應同乘以 $|-1|$ 得到 $|-x + 3| \le 5$，方可對照出 $a = -1, b = 5$！

陷阱 4：兩邊平方去絕對值未確認非負

❌ 錯例：解 $|x - 1| \le x - 3$ 時直接兩邊平方。
✅ 正解：只有確定兩邊均為非負數時方可平方，否則應使用分段討論法更安全！

Topic 1

絕對值不等式與參數反求（經典段考題）

參數反求公式（中心點與半距離）

若已知絕對值不等式 $|x - a| \le b$ 的解範圍為 $c \le x \le d$：

中心點 $a = \frac{c + d}{2}$ （兩端點加起來除以 2）
半距離 $b = \frac{d - c}{2}$ （大減小除以 2）
【範例 1】龍騰 SUPER/POWER 講義：參數反求題型 高頻考題

已知不等式 $|ax + 3| \le b$ 的解為 $-2 \le x \le 8$，求實數 $a, b$ 的值。

【板書步驟】

第一步：幾何中心法找出中心點與半距離
解的範圍為 $[-2, 8]$：
中心點 $m = \frac{-2 + 8}{2} = 3$； 半距離 $r = \frac{8 - (-2)}{2} = 5$。
因此對應標準不等式可寫成 $|x - 3| \le 5$。

第二步：調整係數對齊原題
觀察題目中 $|ax + 3|$ 的常數項是 $+3$，而我們的式子內部是 $-3$。
將 $|x - 3| \le 5$ 兩邊同乘以 $|-1|$：
$|(-1) \cdot (x - 3)| \le 5 \times 1 \Rightarrow |-x + 3| \le 5$。
對比 $|ax + 3| \le b$，即可對照出 $a = -1, b = 5$！

Topic 2

分區討論法（處理多重絕對值）

⚠️ 老師提示：學生常見易錯陷阱！

在分段討論算出 $x$ 的解之後，一定要檢查這個解是否有落在該區段的「假設條件」內！若算出來的解不在該範圍內，屬於「無效解（增根）」，必須嚴格捨去！

【範例 2】南一講義 / 段考經典題：雙重絕對值方程式 必考大題

解方程式 $|x - 1| + |x - 3| = 6$。

【板書步驟】

零點為 $x = 1$ 與 $x = 3$，將數線分成三個區間進行討論：

① 當 $x \ge 3$ 時：
兩式皆正，去絕對值不變號：$(x - 1) + (x - 3) = 6 \Rightarrow 2x - 4 = 6 \Rightarrow x = 5$。
驗證：$5 \ge 3$（符合範圍，為有效解）。

② 當 $1 \le x < 3$ 時：
前正後負：$(x - 1) - (x - 3) = 6 \Rightarrow 2 = 6$（矛盾，此區間無解）。

③ 當 $x < 1$ 時：
兩式皆負，去絕對值加負號：$-(x - 1) - (x - 3) = 6 \Rightarrow -2x + 4 = 6 \Rightarrow x = -1$。
驗證：$-1 < 1$（符合範圍，為有效解）。

綜合以上討論，原方程式的實數解為 $x = 5$ 或 $x = -1$。

【範例 3】龍騰版進階補充（武陵/屏女考題）：整數離散性應用 素養挑戰題

求滿足 $3|a + 1| + 2|b - 3| = 2$ 的整數序對 $(a, b)$ 共有幾組？

【板書步驟】

破題關鍵： 因為 $a, b$ 為整數，所以 $|a+1|$ 與 $|b-3|$ 必為「非負整數」（即 $0, 1, 2, 3, \dots$）。

觀察 $3|a+1|$ 的可能值：
若 $|a+1| \ge 1$，則 $3|a+1| \ge 3$，但原式等號右邊只有 $2$，矛盾！
因此 $|a+1|$ 只能為 $0$。

代回原式：$3(0) + 2|b-3| = 2 \Rightarrow 2|b-3| = 2 \Rightarrow |b-3| = 1$。

• 由 $|a+1| = 0 \Rightarrow a = -1$。
• 由 $|b-3| = 1 \Rightarrow b-3 = 1$ 或 $b-3 = -1 \Rightarrow b = 4$ 或 $b = 2$。

故整數序對 $(a, b)$ 為 $(-1, 4)$ 與 $(-1, 2)$，共 2 組！

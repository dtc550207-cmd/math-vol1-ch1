單元核心觀念心智圖 (Concept Map)

快速掌握指數與指數律三大核心觀念

Branch 01

指數擴充與底數限制

  • • 零與負指數：$a^0 = 1$, $a^{-n} = \frac{1}{a^n}$ ($a \neq 0$)。
  • • 分數指數：$a^{\frac{m}{n}} = \sqrt[n]{a^m}$。
  • • 底數限制：分數與實數指數嚴格限制 $a > 0$，避免邏輯矛盾。
Branch 02

對稱式代換與算幾限制

  • • 設變數 $t$：令 $t = a^x + a^{-x}$，必滿足 $t \ge 2$。
  • • 平方代換：$a^{2x} + a^{-2x} = t^2 - 2$。
  • • 立方代換：$a^{3x} + a^{-3x} = t^3 - 3t$。
Branch 03

連等式與指數方程式

  • • 連等式技巧：$a^x = b^y = k \implies a = k^{\frac{1}{x}}$。
  • • 次方轉換：利用底數倍數關係相除轉化為次方減法。
  • • 恆正判定：換元 $y = a^x > 0$，方程式解出負數必須捨去。

段考常踩四大盲點陷阱

考前自我檢查警示卡

陷阱 1：負數底數盲目套用分數指數律

❌ 錯例：計算 $((-3)^2)^{\frac{3}{2}}$ 時直接次方相乘 $2 \times \frac{3}{2} = 3$ 得到 $(-3)^3 = -27$。
✅ 正解：當底數為負數時不適用分數指數律！必須先算括號內 $(-3)^2 = 9$，再計算 $9^{\frac{3}{2}} = 27$。

陷阱 2：對稱換元 $t = a^x + a^{-x}$ 忽略 $t \ge 2$

❌ 錯例：配方得 $g(t) = (t-1)^2 + 2$，誤以為最小值出現在頂點 $t = 1$。
✅ 正解：由算幾不等式 $t = a^x + a^{-x} \ge 2$，頂點 $t=1$ 不在定義域內！最小值應代入端點 $t = 2$ 計算得出 $3$。

陷阱 3：指數方程式未檢查 $a^x > 0$ 正數條件

❌ 錯例：令 $y = 2^x$，解一元二次方程式得 $y = 4$ 或 $y = -2$，將 $-2$ 保留並試圖求解。
✅ 正解：實數次方的指數式 $2^x > 0$ 恆正！$y = -2$ 必然無解，必須直接捨去。

陷阱 4：連等式題目次方倒數計算粗心

❌ 錯例：由 $8.7^m = 100$ 直接寫出 $8.7 = 100^m$。
✅ 正解：兩邊取 $\frac{1}{m}$ 次方得 $8.7 = 100^{\frac{1}{m}} = 10^{\frac{2}{m}}$，務必注意倒數關係！

課後衝刺小測驗 (5 題)

完成答題後點擊「提交測驗」取得成績與詳細解析！

得分：0 / 100

1. 化簡 $27^{-\frac{2}{3}}$ 之值為何？

2. 已知 $a>0$ 且 $a^x + a^{-x} = 4$，則 $a^{2x} + a^{-2x}$ 的值為何？

3. 設 $x \in \mathbb{R}$，函數 $f(x) = 4^x + 4^{-x} - 2(2^x + 2^{-x}) + 5$ 的最小值為何？

4. 已知 $8.7^m = 100$ 且 $0.0087^n = 100$，則 $\frac{1}{m} - \frac{1}{n}$ 之值為何？

5. 解指數方程式 $4^x - 2^{x+1} - 8 = 0$，其實數解 $x$ 為何？

單元核心觀念心智圖 (Concept Map)

快速掌握常用對數三大核心觀念

Branch 01

常用對數與真數條件

  • • 定義：$10^x = p \iff x = \log p$。
  • • 真數限制：真數必須嚴格滿足 $p > 0$。
  • • 恆等式：$10^{\log p} = p, \quad \log 10^a = a$。
Branch 02

對數律與估算值

  • • 加減與乘除：$\log M + \log N = \log(MN)$，$\log M - \log N = \log(M/N)$。
  • • 次方提至前方：$\log(M^k) = k \cdot \log M$。
  • • 常用對數值：$\log 2 \approx 0.3010, \, \log 3 \approx 0.4771$。
  • • 關鍵公式：$\log 5 = 1 - \log 2 \approx 0.6990$。
Branch 03

位數估算與跨學科應用

  • • 首數與尾數：$\log A = n + d$ ($n \in \mathbb{Z}, \, 0 \le d < 1$)。
  • • 位數與非零位：$n \ge 0 \implies (n+1)$ 位數；$n < 0 \implies$ 第 $|n|$ 位非零。
  • • 地震規模：$\log E = 11.8 + 1.5M \implies$ 規模差 $1$，能量差 $10^{1.5} \approx 31.6$ 倍。

段考常踩四大盲點陷阱

考前自我檢查警示卡

陷阱 1：對數律拆解誤用「分配律」

❌ 錯例：誤以為 $\log (A + B) = \log A + \log B$ 或 $\frac{\log A}{\log B} = \log A - \log B$。
✅ 正解：只有「真數相乘」才可以化為「對數相加」！即 $\log (A \cdot B) = \log A + \log B$。

陷阱 2：負對數首尾數拆解未維持「尾數非負」

❌ 錯例：若 $\log A = -2.3010$，誤以為首數 $n = -2$，尾數 $d = -0.3010$。
✅ 正解：尾數必須滿足 $0 \le d < 1$！正確拆解為 $-2.3010 = -3 + 0.6990$，首數為 $-3$，尾數為 $0.6990$。

陷阱 3：對數方程式求解後漏掉檢驗「真數條件」

❌ 錯例：解 $\log x + \log(x-3) = 1$ 得 $x = 5$ 或 $x = -2$，保留兩個解。
✅ 正解：真數必須大於 0（$x > 0$ 且 $x - 3 > 0 \implies x > 3$），故 $x = -2$ 是增根必須捨去！

陷阱 4：最高位數字與首數概念混淆

❌ 錯例：以為整數部分首數 $n$ 直接決定最高位數字。
✅ 正解：首數 $n$ 決定「位數」或「小數點後第幾位非零」；最高位數字是由尾數 $d$（對照 $\log 1, \log 2, \dots, \log 9$）決定的！
